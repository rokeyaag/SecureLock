Enterprise-Grade Architecture

Built from the ground up for maximum confidentiality and tamper resistance

AES-256-GCM Envelope Cipher

Generates a high-entropy 256-bit Data Encryption Key (DEK). All directory contents are compressed and authenticated with chunked AES-GCM tags.

Email OTP Password Reset

Forgot your password? Receive an encrypted 6-digit one-time password on your registered email to reset your vault credentials in milliseconds.

Dual-Slot Key Wrapping

The DEK is dual-wrapped in Slot 0 (User Password) and Slot 1 (Emergency Recovery Key). Password resets update Slot 0 without re-encrypting gigabytes of data.

Instant Quick-Lock

For huge 50GB-100GB video or gaming directories, applies instant Windows CLSID shell masking and system attribute protection in 0.1 second.

Modern Dark-Themed GUI

Sleek desktop interface with password show/hide eye toggles, password strength analyzer, live progress tracker, and central vault manager.

CLI & 1-Click Desktop Installer

Supports full command-line automation for power users, along with standalone SecureLock.exe installer and Start Menu integration.
